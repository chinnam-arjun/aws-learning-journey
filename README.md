# AWS DevOps Learning Journey

This repository documents my journey from AWS beginner to DevOps engineer.

## Objectives

* Learn AWS core services through hands-on practice.
* Master AWS CLI for automation and administration.
* Understand cloud networking and security concepts.
* Build real-world cloud architectures.
* Learn Infrastructure as Code using Terraform.
* Implement CI/CD pipelines using Jenkins and GitHub Actions.
* Work with Docker and Kubernetes.
* Document all labs, commands, scripts, diagrams, and projects.
