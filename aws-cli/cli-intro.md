# AWS CLI

This section documents my hands-on AWS CLI learning and cloud administration activities as part of my AWS DevOps Learning Journey.

## Why AWS CLI?

While the AWS Management Console is useful for learning and visualizing resources, Cloud Engineers and DevOps Engineers often manage infrastructure using the command line for automation, scalability, and operational efficiency.

## Objectives

* Learn AWS CLI fundamentals
* Understand authentication and authorization
* Practice AWS resource management
* Automate cloud operations
* Develop scripting skills for DevOps workflows

## Topics Covered

* Installation & Configuration
* IAM Authentication and Authorization
* AWS Profiles
* STS Identity Verification
* Output Formats and Querying

## IAM Concepts

* IAM Users
* IAM Roles
* Access Keys
* STS Identity Verification
